# Melhores Promo — Landing Page V2.0

Landing page estática, organizada para GitHub + Vercel.

## Estrutura

- `index.html` — página principal
- `css/styles.css` — estilos
- `js/script.js` — comportamento e tracking dos CTAs
- `assets/logo.png` — logo real do projeto
- `assets/screenshot.jpg` — print real das ofertas
- `.gitignore` — arquivos ignorados pelo Git
- `vercel.json` — configuração simples para deploy
- `README.md` — documentação

## Vercel

Não precisa de build ou instalação de dependências.

No Vercel:
1. Importe o repositório GitHub.
2. Framework Preset: Other / nenhum framework.
3. Build Command: deixe vazio.
4. Output Directory: deixe vazio.
5. Deploy.

## Importante

O link do grupo WhatsApp já está configurado diretamente nos CTAs do HTML.

## Objetivo da V2.0

Fluxo de conversão:
Instagram → Landing Page → CTA → Grupo WhatsApp

A estrutura foi feita para funcionar bem no celular, que é o principal cenário para tráfego vindo do Instagram.
